Privacy Policy

Email Digest Scheduler. Last updated November 4, 2026.

This is a personal tool used only by its owner, on the owner's own Gmail account.

  • What it accesses: the owner's own Gmail messages, through the Gmail API's read-only scope (gmail.readonly).
  • How it uses the data: only to classify replies to job applications and write a daily summary for the owner.
  • Where data is stored: only on the owner's own computer. Messages are processed by a model running locally on that computer.
  • Sharing: no data is sold, shared, or sent to any third party or server.
  • Changes to email: none. The tool never sends, deletes, labels or modifies email.
  • Revoking access: at any time from Google Account → Third-party connections.

The use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Questions: open an issue on GitHub.
